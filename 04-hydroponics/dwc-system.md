# DWC 深水培系统结构与搭建方案

**文档版本：** V1.0  
**适用项目：** 室内叶菜水培试验  
**种植作物：** 生菜、小白菜  
**种植规模：** 首批12–18株  
**系统类型：** DWC（Deep Water Culture，深水培）

## 一、DWC系统的基本原理

DWC是一种将植物根系置于营养液中的水培方式。

植物通过定植篮固定在栽培盖板上，根系向下生长并接触营养液。气泵通过气管和气石向营养液中持续供气，提高溶解氧，满足根系呼吸需求。

系统主要由以下部分组成：

1. 储液箱
2. 栽培盖板
3. 定植篮
4. 气泵
5. 气管和气石
6. 营养液
7. 水质与环境监测设备

## 二、系统结构设计

### 1. 储液箱

建议采用不透光、食品接触级HDPE材质的储液箱。

初始配置：

- 数量：2个
- 单箱标称容量：25–30L
- 要求：避光、耐腐蚀、容易清洗
- 箱盖：能够承载定植篮和植株

注意：标称容量不等于实际营养液容量。应预留空气空间，避免营养液溢出。

### 2. 栽培盖板

盖板安装在储液箱顶部，用于固定定植篮。

要求：

- 材料：防水、耐腐蚀、易清洁
- 颜色：优先不透光
- 开孔：与定植篮尺寸匹配
- 株距：初期可按15–20cm试验，后续根据品种和植株大小调整

盖板必须尽量遮光，减少储液箱内部藻类滋生。

### 3. 定植篮

初期建议采用直径约5cm的定植篮。

每个储液箱根据实际尺寸布置6–9个种植孔。

定植篮底部应允许根系穿出，并保证根系能够接触营养液或湿润环境。

### 4. 供氧系统

供氧系统是DWC的关键设备。

组成：

- 双出口或多出口气泵
- 气管
- 气石
- 分气阀
- 止回阀

基本连接关系：

气泵 → 分气阀 → 气管 → 气石 → 营养液

要求：

- 每个储液箱至少配置一个气石
- 气石放置在箱体底部附近
- 气泵尽量高于液面
- 如果气泵低于液面，应安装止回阀
- 保证气泡分布均匀

建议准备备用气泵，降低停电或设备故障带来的风险。

## 三、系统布局

初始空间：

- 架子尺寸：约90×45×150cm
- 两个储液箱并排或分层放置
- 植物灯安装在植株上方
- 风扇负责空气流动
- 电气设备尽量远离水箱和地面积水区域

设计原则：

1. 便于观察根系和营养液。
2. 便于补水、换液和清洁。
3. 水箱必须能够承受满载重量。
4. 电线和插座避免接触水。
5. 保留检修空间。

注意：25–30L水箱装满水后，仅水的重量就约为25–30kg。货架必须核实单层承重能力，并考虑箱体、盖板及植株的额外重量。

## 四、营养液管理

初始试验参数：

| 项目 | 初始目标 |
|---|---:|
| pH | 6.0 |
| EC | 1.3 mS/cm |
| 营养液温度 | 20℃ |
| 液面 | 保持根系能够接触营养液 |

以上参数是试验起点，不是所有品种和生长阶段的固定最优值。

管理要求：

- 使用适合叶菜的水培A/B营养液。
- 严格按照产品说明配制。
- A液和B液先分别稀释，再加入储液箱。
- 不要直接混合浓缩A液和B液。
- 补水后重新测量EC和pH。
- 定期检查营养液气味、颜色和根系状态。

## 五、DWC日常检查

### 每日检查

- 气泵是否正常运行
- 气石是否持续产生气泡
- 营养液液位是否正常
- 营养液温度是否异常
- 植株是否萎蔫或出现异常
- 根系是否洁白、无明显腐败迹象

### 每周检查

- 校准或检查pH、EC测量设备
- 检查气管是否松脱
- 检查储液箱是否漏水
- 检查根系生长情况
- 记录植株高度和叶片数量

## 六、主要风险及处理

| 风险 | 可能后果 | 预防措施 |
|---|---|---|
| 气泵停机 | 根系缺氧 | 准备备用气泵 |
| 营养液温度过高 | 根系缺氧、病害风险增加 | 加强环境与水温管理 |
| 储液箱漏光 | 藻类滋生 | 使用不透光箱体和盖板 |
| pH异常 | 影响养分吸收 | 定期检测并谨慎调整 |
| EC过高 | 根系渗透胁迫 | 根据检测结果补水或调整营养液 |
| 电气设备进水 | 触电或设备损坏 | 漏电保护、抬高插座、做好滴水防护 |

## 七、首批试验计划

首批以12–18株生菜和小白菜为对象。

试验目标：

1. 验证DWC供氧系统能否稳定运行。
2. 观察不同生长阶段的根系变化。
3. 记录pH、EC和营养液温度。
4. 记录生长周期、成活率和单株重量。
5. 估算每批种植的水、电、肥料及人工成本。

每批结束后，根据记录调整设备和管理参数。
